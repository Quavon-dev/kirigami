# Security policy

## Supported versions

Security fixes go into the newest release for the current Minecraft version. Older Minecraft versions only receive fixes for critical problems.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through GitHub: open the [Security tab](https://github.com/Quavon-dev/kirigami/security) and choose **Report a vulnerability**.

Include the Kirigami version (`/version`), what an attacker can do, and how to reproduce it. We will confirm receipt and keep you updated until the problem is fixed and released.

Vulnerabilities in Paper itself that also affect plain Paper should be reported to [PaperMC](https://github.com/PaperMC/Paper/security) as well.
